## Deskripsi Program
### Kasus 1 - Sistem Kasir Minimarket
Program menghitung subtotal belanja, menentukan diskon, menghitung potongan harga, dan menampilkan total pembayaran pelanggan.

### kasus 2 - Sistem Penilaian Akademik
Program Menghitung nilai akhir berdasarkan nilai tugas, UTS, dan UAS, menentukan grade, serta menampilkan kelulusan mahasiswa.
